怎样读这张图
  1. 1顶部宽度 = 声音电平。对称波形越高，表示这一时刻输入越强；渐宽/渐窄可观察渐强、渐弱及平滑起落。
  2. 2最低而连续的亮线通常是基频 F0。它决定听到的音高；上方近似等间距的平行线是整数倍谐波。
  3. 3线间的蓝色“雾”是非谐波能量。气声、摩擦或不规则振动会增加这种散布；清晰稳定的发声会留下更规整的横线。
  4. 4起音处的竖直边缘反映进入方式。谐波同时突然出现常见于较硬起音；先出现噪声、谐波再渐入则更像送气起音。
  5. 5较亮的谐波群就是共振能量带。舌位、唇形与喉位改变时，这些亮带会整体上移、下移或改变强弱；它们并不是另一个音高。
  6. 6重点观察 2–4 kHz 与 0–1 kHz 的能量比。比值升高常对应更集中的高频能量与更明亮/更“窄”的声学结果；请用同一手机距离做前后对比。
